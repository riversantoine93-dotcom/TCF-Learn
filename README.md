# TCF LEARN — Vercel Deployment

This is the full Next.js course site for **Turning Forward: The Work Beyond Fear**.

## Included
- TCF LEARN branding/logo
- 8 course modules
- 24 lessons
- dashboard and local progress tracking
- reflections and knowledge checks
- Module 1, Video 1 installed
- no Netlify configuration
- no Stripe/Supabase required for this content-first build

## Deploy to Vercel
1. Extract this ZIP.
2. Create or clean a GitHub repository.
3. Upload the **contents** of this folder so `package.json` and `app/` are visible at the repository root.
4. In Vercel, choose **Add New → Project**.
5. Import the GitHub repository.
6. Framework Preset: **Next.js**
7. Root Directory: leave blank.
8. Build Command: use Vercel default.
9. No environment variables are required.
10. Deploy.

## Important
Do not upload the enclosing folder as another nested directory. At the repository root you should see:
- `app/`
- `components/`
- `lib/`
- `public/`
- `package.json`
